## Problem Statement

<span style="font-size: 14pt;">Given a number **n**, return all the combinations of balanced parentheses of length n.</span>
<span style="font-size: 14pt;">**Note:** A sequence of parentheses is **balanced** if every opening bracket has a corresponding closing bracket in the **correct order**.</span>
<span style="font-size: 14pt;">For example, "(())", "()()", and "(()())" are balanced, whereas ")()(", "))((", and "()))" are not.</span>

<span style="font-size: 14pt;">**Examples:**</span>

<span style="font-size: 14pt;">**Input**: n = 6
**Output: **["((()))", "(()())", "(())()", "()(())", "()()()"]
**Explanation:** These are the only possible valid balanced parentheses.</span></pre>

<span style="font-size: 14pt;">**Input**: n = 4
**Output: **["(())", "()()"]
**Explanation:** These are the only possible valid balanced parentheses.</span></pre>
<div><span style="font-size: 14pt;">**Constraints: **</span>
<span style="font-size: 14pt;">1 ≤ n ≤ 16</span></div>
<div><span style="font-size: 14pt;">n % 2 == 0</span></div>
