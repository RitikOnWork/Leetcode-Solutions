## Problem Statement

<span style="font-size: 18px;">Given a stack of integers **st[]**. Sort the stack in **ascending order** (smallest element at the bottom and largest at the top).</span>

<span style="font-size: 18px;">**Examples:**</span>

<span style="font-size: 18px;">**Input: **st[] = [41, 3, 32, 2, 11]<strong>
Output: </strong>[41, 32, 11, 3, 2]<strong>
Explanation: </strong>After sorting, the smallest element (2) is at the bottom and the largest element (41) is at the top.

<span style="font-size: 18px;">**Input: **st[] = [3, 2, 1]
**Output: **[3, 2, 1]<strong>
Explanation: </strong>The stack is already sorted in ascending order.

<span style="font-size: 18px;">**Constraints:**
1 ≤ st.size() ≤ 10<sup>3
</sup>0 ≤ stack element ≤ 10³^&ⁿ^b^s^p^;</span>
