## Problem Statement

<span style="font-size: 14pt;"><span style="font-size: 14pt;">Given an array </span>**arr[]**<span style="font-size: 14pt;"> of integers and another integer </span>**target**<span style="font-size: 14pt;">. Determine if there exist **two distinct indices** such that the **sum** of their elements is equal to the **target.**</span></span>

<span style="font-size: 14pt;">**Examples:**</span>

<span style="font-size: 14pt;">**Input: **arr[] = [0, -1, 2, -3, 1], target = -2
**Output: **true
**Explanation:** arr[3] + arr[4] = -3 + 1 = -2</span></pre>

<span style="font-size: 14pt;">**Input: **arr[] = [1, -2, 1, 0, 5], target = 0
**Output:** false
**Explanation:** None of the pair makes a sum of 0
</span></pre>

<span style="font-size: 14pt;">**Input: **arr[] = [11], target = 11
**Output:** false
**Explanation:** No pair is possible as only one element is present in arr[]</span></pre>

<span style="font-size: 14pt;">**Constraints:**
1 ≤ arr.size ≤ 10⁵
-10⁵ ≤ arr[i] ≤ 10<sup>5
</sup><span style="font-size: 18.6667px;">-2*10⁵ ≤ target ≤ 2*10</span>⁵</span>
