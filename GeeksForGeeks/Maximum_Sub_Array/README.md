## Problem Statement

<span style="font-size: 14pt;">Given an array of integers **arr[]**, find the contiguous subarray with the **maximum sum **that contains only non-negative numbers. If multiple subarrays have the same maximum sum return the one with **longest length.** If there is still a tie, return the subarray with the **smallest starting index**. If the array contains only **negative** numbers, return **-1**.</span>

<span style="font-size: 14pt;">**Note: **A subarray is a contiguous non-empty sequence of elements within an array.</span>

<span style="font-size: 14pt;">**Examples:**</span>

<span style="font-size: 14pt;">**Input: **arr[] = [1, 2, 3]
**Output:** [1, 2, 3]
**Explanation:** In the given array, every element is non-negative, so the entire array [1, 2, 3] is the valid subarray with the maximum sum.
</span></pre>

<span style="font-size: 14pt;">**Input: **arr[] = [-1, 2]
**Output:** [2]
**Explanation:** The only valid non-negative subarray is [2], so the output is [2].
</span></pre>

<span style="font-size: 14pt;">**Input: **arr[] = [1, 2, 5, -7, 2, 6]
**Output:** [1, 2, 5]
**Explanation:** The valid non-negative subarrays are [1, 2, 5] and [2, 6]. Both have the same sum of 8, but [1, 2, 5] starts earlier and also longest one so it is the preferred subarray.</span></pre>

<span style="font-size: 14pt;">**Constraints:**
1 ≤ arr.size() ≤ 10⁶
-10⁵^&ⁿ^b^s^p^;≤ arr[i] ≤ 10⁵</span>
