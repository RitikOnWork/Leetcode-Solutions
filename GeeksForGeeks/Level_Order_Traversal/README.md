## Problem Statement

<span style="font-size: 14pt;"><span style="font-size: 18px;">Given the **root **of a Binary Tree, your task is to return its </span><span style="font-size: 18px;">Level Order Traversal</span><span style="font-size: 18px;">.</span></span>

**<span style="font-size: 18.6667px;">Note: </span>**<span style="font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Oxygen, Ubuntu, Cantarell, 'Open Sans', 'Helvetica Neue', sans-serif; font-size: 14pt;">A level order traversal is a breadth-first search (BFS) of the tree. It visits nodes level by level, starting from the root, and processes all nodes from left to right within each level before moving to the next.</span>

<span style="font-size: 14pt;">**Examples:**</span>

<span style="font-size: 14pt;">**Input:** root = [1, 2, 3]
<img src="https://media.geeksforgeeks.org/img-practice/prod/addEditProblem/700511/Web/Other/blobid0_1758799933.webp" width="345" height="213">
**Output: **[1, 2, 3]
**Explanation: **</span><span style="font-size: 18.6667px;">We start with the root node 1, so the first level of the traversal is [1]. Then we move to its children 2 and 3, which form the next level, giving the final output [1, 2, 3].</span></pre>

<span style="font-size: 14pt;">**Input:** root = [10, 20, 30, 40, 50, N, N]
<img src="https://media.geeksforgeeks.org/img-practice/prod/addEditProblem/700511/Web/Other/blobid1_1758800199.webp" width="336" height="234">
**Output: **[10, 20, 30, 40, 50]
**Explanation: **</span><span style="font-size: 18.6667px;">We begin with the root node 10, which forms the first level as [10]. Its children 20 and 30 make up the second level, and their children 40 and 50 form the third level, resulting in [10, 20, 30, 40, 50].</span></pre>
