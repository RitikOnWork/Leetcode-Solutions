# Count Pairs Divisible By K

## Problem Statement

<span style="font-size: 18px;">Given an array **arr[] **and positive integer **k**, count total number of pairs in the array whose sum is divisible by **k**.</span>

<span style="font-size: 18px;">**Examples:**</span>

<span style="font-size: 18px;">**Input :**  arr[] = [2, 2, 1, 7, 5, 3], k = 4
**Output :** 5
**Explanation : **There are five pairs possible whose sum is divisible by '4' i.e., (2, 2), (1, 7), (7, 5), (1, 3) and (5, 3).</span></pre>

<span style="font-size: 18px;">**Input :** arr[] = [5, 9, 36, 74, 52, 31, 42], k = 3
**Output :** 7 
**Explanation : **There are seven pairs whose sum is divisible by 3, i.e, (9, 36), (9,42), </span><span style="font-size: 18px;">(74, 52), (36, 42), (74, 31), (31, 5) and (5, 52).
</span></pre>
<div><span style="font-size: 18px;">**Constraints :**</span></div>
<div><span style="font-size: 18px;">1 ≤ |arr| ≤ 5*10⁴</span></div>
<div><span style="font-size: 18px;">1 ≤ arr[i] ≤ 10⁶</span></div>
<div><span style="font-size: 18px;">1 ≤ k ≤ 5*10⁴</span></div>
