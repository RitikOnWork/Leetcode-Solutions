## 📝 Problem Statement

Given an integer array of size `n`, find all elements that appear more than `&lfloor;n / 3&rfloor;` times.

---

## 💡 Examples

**Example 1:**

**Input:** nums = [3,2,3]
**Output:** [3]
</pre>

**Example 2:**

**Input:** nums = [1]
**Output:** [1]
</pre>

**Example 3:**

**Input:** nums = [1,2]
**Output:** [1,2]
</pre>
