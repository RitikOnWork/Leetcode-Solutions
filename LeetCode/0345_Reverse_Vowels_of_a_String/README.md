# 0345. Reverse Vowels of a String

## 🔗 Original Problem

[LeetCode - Reverse Vowels of a String](https://leetcode.com/problems/reverse-vowels-of-a-string/)

---

## 📝 Problem Statement

Given a string `s`, reverse only all the vowels in the string and return it.

The vowels are `'a'`, `'e'`, `'i'`, `'o'`, and `'u'`, and they can appear in both lower and upper cases, more than once.

---

## 💡 Examples

**Example 1:**

<div class="example-block">

**Input:** <span class="example-io">s = "IceCreAm"</span>

**Output:** <span class="example-io">"AceCreIm"</span>

**Explanation:**

The vowels in `s` are `['I', 'e', 'e', 'A']`. On reversing the vowels, s becomes `"AceCreIm"`.
</div>

**Example 2:**

<div class="example-block">

**Input:** <span class="example-io">s = "leetcode"</span>

**Output:** <span class="example-io">"leotcede"</span>
</div>
